# VocaShot — AI 단어 학습 플랫폼

단어장을 사진/PDF로 올리면 AI가 단어를 추출해 데이터베이스에 저장하고,
그 단어로 시험지를 생성한 뒤, 사용자가 풀면 AI가 자동으로 채점해 주는 웹 서비스입니다.

## 주요 기능

1. **단어장 업로드 & OCR 추출** — PDF/이미지를 올리면 Gemini가 단어·뜻·정의·예문·페이지를 추출(진행바 표시). 사용자가 이름·설명을 붙여 저장.
2. **시험지 생성** — 단어를 번호/페이지 범위로 선택하고 형식을 골라 AI로 문제 생성(진행바 표시). 저장됨.
   - 형식: TOEFL Style / SAT Style / 단어→뜻 / 뜻→단어 / 주관식(뜻 채워넣기)
3. **시험 응시** — 저장된 시험지를 풀기. 시간 제한 옵션. 제출 시 AI 자동 채점, 결과 저장. 여러 번 응시 가능하며 모든 기록 보존.
4. **로그인/회원가입** — 이메일 인증 포함. 비밀번호 강화 규칙(6~15자, 영문+숫자+특수문자). 테스트 계정 자동 생성.
5. **PDF 다운로드** — 시험지 PDF, 결과 리포트 PDF.
6. **프로필** — 닉네임 설정, 프로필 사진 업로드 + **크롭/리사이즈**(드래그 위치 조정·확대축소, 256×256 정사각형으로 저장).
7. **다크 모드** — 상단 🌙/☀️ 토글, 시스템 설정 자동 감지, 선택 저장(localStorage).
8. **회원 등급 (3단계)** — 기본(Basic, 무료) / 프리미엄(Premium, 유료) / **선생님(Teacher, 유료·최상위)**. 회원가입 시 일반/선생님 유형 선택(선생님은 반 개설·학생 관리 가능). 프로필에서 요금제 카드로 사용량·한도 확인 및 전환(데모용, 실결제 추후).
9. **통계 대시보드(메인)** — 로그인하면 첫 화면에 KPI(단어장·총 단어·시험지·응시 횟수·평균/최고 점수), 점수 추이 라인 차트, 최근 응시 기록 표시.
10. **SRS 간격 반복 복습** — 시험에서 틀린 단어가 복습 큐에 쌓이고, 망각곡선(1→2→4→8→16→35일) 스케줄로 "잊을 때쯤" 다시 출제. 대시보드에 "오늘 복습할 단어 N개" 배너 → 로컬 4지선다 복습(AI 호출 없음, 같은 단어장 뜻을 오답 보기로 사용). 맞히면 간격이 늘고, 틀리면 즉시 복습 대상.
11. **취약 단어 분석** — 단어별 숙련도 추적(정복/학습중/취약). 대시보드에 숙련도 분포 막대 + "취약 단어 TOP"(정확도·오답 횟수) 표시. → 학부모 리포트(2단계)·학원 모드(3단계)의 데이터 토대.
12. **학습 기능** — 🎴 플래시카드(단어↔뜻 3D 뒤집기, 섞기/이전/다음), 🎮 단어 맞추기 게임(단어·뜻 타일 짝맞추기, 타이머·정답 애니메이션). 단어장 상세에서 실행.
13. **관리** — 대시보드 카드에서 단어장·시험지 바로 삭제, 프로필에서 통계 초기화(응시 기록·숙련도만 삭제, 단어장/시험지는 유지).
14. **다국어 단어장** — 단어장마다 언어 선택(🇺🇸 영어 / 🇨🇳 중국어). 중국어는 병음(pinyin)까지 추출·표시(단어 목록·플래시카드), 문제 생성도 언어에 맞춰 출제. 뜻은 한국어.
15. **학부모 리포트 공유** — 프로필에서 읽기전용 진도 리포트 링크 발급(`/report.html?t=토큰`). 학부모는 로그인 없이 KPI·점수 추이·숙련도·취약 단어·최근 응시를 확인. 링크는 언제든 재발급/중단 가능.
16. **학원 · 교사 모드** — 대시보드 "🏫 학원" 탭. **선생님 회원만** 반을 만들고(참여 코드 발급) 자신의 시험지를 반에 배정하며, 반 성적 대시보드에서 학생×시험지별 최고 점수를 한눈에 확인. 일반/프리미엄 회원은 참여 코드로 반에 들어가 배정된 시험지를 응시만 가능(자동 채점, 기록 저장). B2B2C 수익 모델의 토대.
17. **AI 예문 첨삭** — 플래시카드를 뒤집으면 그 아래에 예문 입력창이 열리고, AI가 단어를 용법·문맥에 맞게 썼는지 첨삭(맞음/틀림 + 한국어 피드백 + 교정 문장). **프리미엄/선생님 회원 전용**(일반 회원은 잠금 안내).
18. **세련된 UI** — 인앱 팝업 모달(반 만들기 등, 브라우저 prompt 제거), 토스트 알림, 요금제 카드, 포커스 링·그림자 등 현대적 디자인.

## 실행 방법

```bash
./run.sh
```

또는 수동으로:

```bash
python3 -m venv venv
./venv/bin/pip install -r requirements.txt
./venv/bin/uvicorn app:app --reload --port 8000
```

브라우저에서 **http://127.0.0.1:8000** 접속.

> PDF 처리를 위해 `poppler`가 필요합니다 (macOS: `brew install poppler`).

```
# SMTP_PORT=587
# SMTP_USER=you@gmail.com
# SMTP_PASSWORD=app_password
# SMTP_FROM=you@gmail.com
```

## 구조

```
app.py          FastAPI 라우트 (인증/단어장/시험지/응시/PDF)
database.py     SQLite 스키마 & 접근 헬퍼
auth.py         비밀번호 해싱, 세션, 이메일 인증
progress.py     장시간 작업 진행 상황 인메모리 스토어 (진행바)
ai_extract.py   PDF/이미지 → 단어 추출 (Gemini OCR)
ai_quiz.py      문제 생성 & 채점 (Gemini)
pdf_export.py   시험지/리포트 PDF 생성 (reportlab)
static/         프론트엔드 (index.html / app.js / style.css)
fonts/          한글 PDF 폰트
data/           SQLite DB (자동 생성)
uploads/        업로드 파일 (자동 생성)
```
