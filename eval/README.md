# VocaShot-AI 채점 평가 (On-device Gemma 2B vs Cloud Gemini)

## 목적
학생 답안을 **제3자 상용 AI(Gemini)에 보내지 않고** 기기 안(Gemma 2B)에서 채점할 때,
**정확도와 공정성**이 얼마나 유지되는지 정량적으로 측정한다.
(IRR "The Algorithmic Classroom"이 진단한 *데이터 주권·채점 편향* 불평등에 대한 개입의 실증 평가.)

## 연구 질문
1. **정확도** — 각 모델(Gemma / Gemini)이 **사람 채점(정답 기준)** 과 얼마나 일치하나?
2. **동의어 관용** — 뜻은 맞지만 표현이 다른 답("반대로"→"역으로")을 정답으로 인정하나?
   (못 하면 표현이 다른 학생이 불이익 → 형평성 문제)
3. **과잉 관대(false positive)** — 틀린 답을 정답 처리하나?
   (너무 후하면 학생이 오개념을 정답으로 착각 → 학습 저해)
4. **공정성 슬라이스** — 오타·부분정답·경계 표현을 부당하게 감점하나?

## 데이터: `benchmark.json`
실제 단어장 단어 12개 × 여러 답안 유형(총 40문항). 각 항목:
- `word`, `correct_ans` : 문제 단어와 정답 뜻
- `student_ans` : 채점 대상(가상 학생 답)
- `category` : `exact`(정확) / `synonym`(동의어) / `partial`(부분) / `typo`(오타) / `borderline`(경계) / `wrong`(오답) / `empty`(무응답)
- `human` : **사람 정답 기준**(ground truth). `true`/`false`

> **한계(정직하게):** 지금은 방법 증명용 **합성 데이터**다. 실제 학생 답안은 9월 파일럿에서 수집해 교체·확장한다.
> 편향 축은 답안이 한국어이므로 "비원어민 영어"가 아니라 **동의어 관용·과잉 관대·표현 공정성**으로 정의했다.

## 절차
1. **사람 채점(Day 2):** `human`이 `null`인 판단 항목(동의어/부분/오타/경계)을 사람이 채운다.
   명백한 항목(exact/wrong/empty)은 미리 채워둠 — 검토만.
2. **모델 채점(Day 3):**
   - Gemini: 서버 `_grade_written`으로 40문항 채점
   - Gemma: 브라우저에서 `gradeWrittenOnDevice`로 40문항 채점
3. **분석:** 각 모델의 `correct`를 `human`과 비교 → 정확도/일치율, 카테고리별 오류(특히 synonym·wrong), 혼동표.
