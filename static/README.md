# VoQuiz 소개 사이트

VoQuiz 앱을 소개하는 원페이지 랜딩 사이트입니다. Apple 스타일(큰 타이포·넉넉한 여백·
스크롤 등장 애니메이션·유리 질감 내비게이션)로 제작했습니다. (구 브랜드명: VocaShot)

## 실행

빌드 과정이 없는 순수 정적 사이트입니다. 파일을 그대로 열거나 간단히 서버로 띄우면 됩니다.

```bash
# 방법 1: 로컬 서버 (권장)
python3 -m http.server 8080
# → http://127.0.0.1:8080

# 방법 2: 그냥 열기
open index.html
```

## 구성

```
index.html    한 페이지 전체 (섹션별 마크업)
style.css     디자인 시스템 · 레이아웃 · 애니메이션
script.js     스크롤 등장, 내비 상태, 목업 틸트, 숫자 카운트업
assets/       로고 · 파비콘
```

## 디자인 노트

- **폰트**: 시스템 스택(`-apple-system` → macOS에서 SF Pro / Apple SD Gothic Neo)이라 별도 웹폰트 로딩이 없습니다.
- **색상**: Apple 팔레트 기반 (`#fbfbfd`, `#f5f5f7`, `#1d1d1f`, `#6e6e73`, `#0071e3`) + VoQuiz 포인트 컬러(블루·바이올렛).
- **모든 목업은 CSS/SVG로 직접 그렸습니다** — 외부 이미지·라이브러리 의존성이 없습니다.
- `prefers-reduced-motion`을 존중해 애니메이션을 끕니다.
- 반응형: 900px 이하에서 내비 링크 숨김, 그리드 1~2열로 재배치.

> 앱 본체는 상위 폴더의 `VocaShot - Claude/` 에 있습니다. (VoQuiz로 리브랜딩, 라이브: https://voquiz.com)
>
> 관리자 편집: 푸터의 "관리자" 링크 → 비밀번호(`admin.js`의 `ADMIN_PW`) 로그인 → 소식 관리·문구 편집·내보내기.
